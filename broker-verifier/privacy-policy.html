2. Data Collection and Usage

SafeShield operates under a strict data-minimization and zero-knowledge architecture. We do not require account registration or collect personally identifiable information (PII) to use the extension.

  • Active Domain Verification: When you navigate to a website or click the SafeShield extension icon, the extension parses only the top-level domain hostname (e.g., example.com) to match it against our database of 34,670+ blacklisted entities compiled from 15 global supervisory regulators (including SEC, CFTC, FCA, BaFin, FINMA, AMF, CNMV, ASIC, and MAS).
  • Zero URL Parameter Tracking: SafeShield does not extract, send, or record full URL pathnames, query parameters, passwords, form entries, or tokenized session data.
  • Manual Scam Search: When you manually input a broker name or search query into the extension popup, that query is sent via secure TLS/HTTPS to isbrokersafe.com solely to retrieve verified regulatory status. Queries are not tied to any user identifier.

3. Chrome Extension Permissions Justification

In accordance with Google Chrome Web Store Developer Policies, SafeShield requests only the minimal necessary permissions required to fulfill its security functions:

  • activeTab & tabs: Required solely to read the hostname of the currently active browser tab to display real-time safety badges (e.g., "Regulated Broker", "Unregulated Warning", or "Neutral Domain"). No history or background tabs are indexed.
  • storage: Used locally on your device to store offline threat hashes, user theme preferences, and minimize network requests. No personal information is stored.
  • host_permissions: Limited strictly to https://isbrokersafe.com/*, https://verifydating.net/*, and https://dating-photo-checker.onrender.com/* to fetch real-time regulatory status updates and biometric hash matches.
