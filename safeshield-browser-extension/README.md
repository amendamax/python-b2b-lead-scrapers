# SafeShield — Browser Security Extension (Chrome / Edge / Brave / Opera)
Built by VasileDev Group (Vasile Bratu)

## How to Install Locally:
1. Open Google Chrome or Microsoft Edge.
2. Navigate to `chrome://extensions` (or `edge://extensions`).
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** (*Încarcă extensie dezarhivată*).
5. Select this folder: `C:\\Users\\bratu\\Documents\\antigravity\\amazing-borg\\safeshield-browser-extension`.
6. SafeShield is now live in your browser toolbar!

## Features:
- **Auto-Shield Badge**: Turns **GREEN (SAFE)** on regulated brokers, **RED (RISK)** on CONSOB/FCA blacklisted scams.
- **Instant Search**: Check any broker or domain against 14,660+ regulatory databases in under 100ms.
- **Direct Dating Scam Launcher**: One-click jump to VerifyDating biometric scanner.
